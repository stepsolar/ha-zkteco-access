Automazioni Home Assistant

      
Ogni porta crea in Home Assistant (via MQTT) una serratura, un pulsante Apri, un interruttore Sempre aperta, i sensori porta/allarme, l'ultimo evento e un'entità evento per le automazioni. Comandi avanzati sul topic zkteco_access/cmd:


service: mqtt.publish
data:
  topic: zkteco_access/cmd
  payload: >
    {"action":"grant","card":"2095868724","name":"Rossi","grp":"101",
     "levels":["101","Cancello"],"start_date":"2026-11-18","end_date":"2026-11-21"}

# altre azioni: open (door, seconds), close, normal_open (door, enable),
# revoke (card|pin), disable / enable (card|pin), cancel_alarm, restart,
# sync_time, sync_all, learn (timeout)
# esito su zkteco_access/cmd/result
